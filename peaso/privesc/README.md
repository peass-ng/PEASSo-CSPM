# peaso.privesc

Privilege-escalation technique catalog (YAML, `catalog/<provider>/*.yaml`) and the
read-only evaluator that turns catalog × snapshot into principal → principal edges for
the Privilege Escalation Map.

How the catalog, evaluator and HackTricks sync work: [Privilege escalation analysis](../../docs/privesc.md).
How to run the privilege-escalation tests: [Testing](../../docs/testing.md).
