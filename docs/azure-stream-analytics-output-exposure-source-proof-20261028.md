# Stream Analytics output exposure source proof

- The [Outputs List By Streaming Job REST operation](https://learn.microsoft.com/en-us/rest/api/streamanalytics/outputs/list-by-streaming-job?view=rest-streamanalytics-2020-03-01) is a read-only child LIST. Its response identifies each configured output, its destination type, and type-specific destination properties. The example and schemas include Data Lake `tenantId`, storage account names, SQL server/database names, Service Bus namespaces, Functions app names, and credential-bearing fields such as `apiKey` and `password`.
- The [Streaming Jobs List REST operation](https://learn.microsoft.com/en-us/rest/api/streamanalytics/streaming-jobs/list?view=rest-streamanalytics-2020-03-01) reports job state. A configured output on a stopped job is a dormant route.
- Destination account names, servers, and namespaces generally do not supply their owning subscription or tenant in the output DTO. The management LIST also does not prove that a query currently sends records to a particular output or reveal effective access held by destination credentials. Thus only an explicit differing Data Lake tenant ID supports a deterministic foreign-tenant verdict; other output ownership remains UNKNOWN.
- `peaso.collectors.azure._embed` makes the output LIST through the existing per-scan reader, validates child identity and type, and retains only destination identity fields. `peaso.analysis.internet_exposure._azure_stream_analytics_job` compares an explicit destination tenant with verified scan tenant metadata and reports incomplete LISTs as UNKNOWN.
