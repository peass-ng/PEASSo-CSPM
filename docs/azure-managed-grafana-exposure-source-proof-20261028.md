# Azure Managed Grafana exposure source proof

- [Managed Grafana Grafana List](https://learn.microsoft.com/en-us/rest/api/managed-grafana/grafana/list?view=rest-managed-grafana-2025-08-01) documents the paged read-only subscription `GET`, the workspace `endpoint`, `publicNetworkAccess`, `provisioningState`, and `grafanaConfigurations.snapshots.externalEnabled`. The same representation can contain SMTP passwords, so the collector projects only exposure fields before retaining rows.
- [Managed Grafana private access](https://learn.microsoft.com/en-us/azure/managed-grafana/how-to-set-up-private-access) states that a workspace is publicly accessible by default and disabling public access restricts traffic to a private endpoint.
- [Managed Grafana data-plane authentication](https://learn.microsoft.com/en-us/azure/managed-grafana/how-to-authenticate-data-plane-api) documents Entra tokens for audience `https://dashboard.azure.com` to query the workspace's Grafana API.
- [Grafana Snapshot API](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/api-legacy/snapshot/) documents read-only `GET /api/dashboard/snapshots`, including external state, external URL, and expiry. The collector requests up to 10,000 rows, rejects a full-cap list as potentially truncated, and retains only external state and expiry. Snapshot keys and capability URLs are discarded.
- [Managed Grafana snapshot configuration](https://learn.microsoft.com/en-us/azure/managed-grafana/grafana-settings) explains that external snapshot publishing can make dashboards public at an external URL. The configuration flag is a capability; the snapshot list establishes whether an unexpired share was published.

`peaso/collectors/azure.py` binds a Grafana data-plane host to an already collected ARM workspace endpoint, requires the documented Grafana token audience and exact read-only snapshot path, and uses the shared per-scan request cache. `peaso/analysis/internet_exposure.py` reports a public HTTPS workspace listener or a currently unexpired external snapshot as `FAIL`. A private-only workspace with a complete empty or expired external-snapshot list is `PASS`; incomplete data-plane inventory is `UNKNOWN` when the public listener is closed.

Focused fake-transport tests in `tests/test_peaso_azure_managed_grafana_exposure.py` cover workspace and data-plane reads, secret-safe projection, public/private decisions, an active external snapshot, and incomplete inventory. No Azure write operation is used.
