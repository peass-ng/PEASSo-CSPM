# GCP native-final hosted gate preparation v1

The recommended saved GCP snapshot is scan
`0864235ed9db4305a594e55bf8bceb82`. The exact pre-AI, final, and snapshot
gzip objects are private under `~/peaso-work/native-final-gcp-private/` and
are bound by SHA-256 and matching snapshot IDs. The [baseline recipe](native-final-gcp-baseline-recipe-v1.json)
records its production connector, request selection, and stage timestamps.

`scripts/prepare_gcp_native_final_hosted.py` builds private, source-pinned
common inputs and paired plans for the existing Linux/amd64 b09 Hardening
reviewer image, `gpt-5.6-sol` with high thinking, six reviewer slots, and
0.5 vCPU/2 GiB per reviewer. `scripts/run_gcp_native_final_hosted.py
--preflight` validates document IDs and hashes, image identity, credential
mode, model catalog entitlement, and pinned runner source. These commands
start no model. The `--launch` path additionally requires root to place the
exact line `ROOT_RELEASE_GCP_NATIVE_FINAL_0864235E` in
`~/peaso-work/CODEX_FINDINGS.txt`. The release line is absent while the AWS
production scan owns the exclusive replay slot.

The exact saved queue has 265 baseline Hardening FAIL inputs, 7 selected
native-final FAILs, and 258 remaining candidate AI inputs. Group planning
has 206 baseline versus 201 candidate initial representatives, packed into
six initial batches in both arms. Applying saved verdicts projects one
recheck batch in each arm, or seven total tasks per arm. This is a task and
input projection, not model-call, token, wall, or CPU/RSS evidence. The five
removed initial representatives and seven selected rows may change prompt
context for the remaining AI findings; paired current-model output must be
measured.

After an explicitly released run, `scripts/summarize_gcp_native_final_hosted.py`
validates complete review IDs, identical model and credential, exact review
and projected finding differences, Priorities input hashes, saved action
references, model calls, tokens, wall time, and CPU × peak RSS. It always
leaves `qualified: false` for root review. Hosted Priorities actions are not
regenerated by this Hardening harness, so saved action preservation is
reported separately from model-generated action quality.

The GCP manifest remains pending hosted qualification and runtime admission
is zero. No push, deployment, production scan, or model replay was made in
this preparation.
