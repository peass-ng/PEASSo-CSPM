# Azure Bastion exposure source proof

Microsoft's [Bastion architecture guide](https://learn.microsoft.com/en-us/azure/bastion/design-architecture) says a regular dedicated deployment accepts client connections through a public IP, while private-only Premium deployment has no internet-routable client IP. The [security guide](https://learn.microsoft.com/en-us/azure/bastion/secure-bastion) identifies TCP 443 as public client ingress and describes NSG restrictions on the Bastion subnet. [Bastion configuration](https://learn.microsoft.com/en-us/azure/bastion/configuration-settings) distinguishes Developer shared infrastructure, which has no customer public IP, from dedicated SKUs.

The [Bastion Host GET schema](https://learn.microsoft.com/en-us/rest/api/virtualnetwork/bastion-hosts/get?view=rest-virtualnetwork-2026-01-01) supplies SKU, provisioning state, private-only state, Developer DNS and IP ACLs, public IP and subnet references, and the shareable-link feature flag. The collector uses one cached full GET per selected host and retains only those exposure fields. The detector joins the already selected public-IP, VNet/subnet, and NSG inventory. It treats missing or malformed paths as `UNKNOWN`; a configured public IP and admitted client port 443 are exposed. Developer's shared DNS and public-client ACLs are evaluated separately.

Microsoft's [shareable-link guide](https://learn.microsoft.com/en-us/azure/bastion/shareable-link) says a link lets a person without Azure credentials reach a VM sign-in prompt; the person still needs VM credentials. The [Get Bastion Shareable Link API](https://learn.microsoft.com/en-us/rest/api/virtualnetwork/get-bastion-shareable-link/get-bastion-shareable-link?view=rest-virtualnetwork-2025-05-01) returns issued URLs for the requested VMs. The [PowerShell GET example without a target VM](https://learn.microsoft.com/en-us/powershell/module/az.network/get-azbastionshareablelink?view=azps-16.0.0) shows enumeration of existing links. The collector requests that read-only operation once per host with sharing enabled and handles validated continuation pages. It stores only the target VM IDs and link presence, never URL tokens. An incomplete list stays `UNKNOWN`.
