# Azure Attestation exposure source proof

The [Microsoft.Attestation provider resource schema](https://learn.microsoft.com/en-us/azure/templates/microsoft.attestation/attestationproviders) exposes `publicNetworkAccess`, `attestUri`, `status`, and `tpmAttestationAuthentication`. [Microsoft's private endpoint guide](https://learn.microsoft.com/en-us/azure/attestation/secure-attestation) states that disabling public access prevents data-plane traffic from the public internet. The [Azure policy definition](https://learn.microsoft.com/en-us/azure/attestation/policy-reference) identifies enabled public access as an exposed service. The [CLI provider show example](https://learn.microsoft.com/en-us/azure/attestation/quickstart-azure-cli) shows a Ready provider and its HTTPS attestation URI. The [SDK status model](https://learn.microsoft.com/en-us/python/api/azure-mgmt-attestation/azure.mgmt.attestation.models.statusresult?view=azure-python) documents Ready, NotReady, and Error states and the TPM authentication field.

The collector performs one full provider GET for each listed provider before interpreting these fields. It retains only the status, URI, public-network setting, TPM authentication setting, trust model, and private endpoint connection IDs and approval states. The [provider schema](https://learn.microsoft.com/en-us/azure/templates/microsoft.attestation/attestationproviders) also permits private JWK fields in policy signing certificates; these are discarded before snapshot persistence. Public access Disabled is a closed network path. Enabled with Ready status and a valid HTTPS URI is a configured TCP/443 public listener. Missing full GET, access state, readiness, or URI remains UNKNOWN. The TPM setting describes the TPM attestation API only; other attestation methods may have separate authentication requirements.
