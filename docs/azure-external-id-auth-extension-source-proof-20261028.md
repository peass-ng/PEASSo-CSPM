# Microsoft Entra External ID authentication callback source proof

- [Custom authentication extensions LIST](https://learn.microsoft.com/en-us/graph/api/identitycontainer-list-customauthenticationextensions?view=graph-rest-1.0) is a read-only Graph GET that returns the derived extension type and `endpointConfiguration.targetUrl`. [Authentication event listeners LIST](https://learn.microsoft.com/en-us/graph/api/identitycontainer-list-authenticationeventlisteners?view=graph-rest-1.0) returns handlers that reference extension IDs and application conditions. The collector reads each list once per tenant and retains only endpoint hostname, extension/listener IDs, event type, and selected application IDs. Full URLs, paths, queries, auth configuration, and free-text fields are discarded.
- [External ID custom authentication extensions](https://learn.microsoft.com/en-us/entra/external-id/customers/concept-custom-extensions) send HTTP calls during sign-up and token issuance containing user profile, authentication request, and event context. The native detector reports a callback to a host outside verified tenant domains only when a collected listener references the extension. Missing listener or domain evidence remains UNKNOWN; an unreferenced extension is dormant for this route.
- This change covers the authentication callback route only. Cross-tenant access policy, guest access, consumer user flows, and application authorization require separate review before the Microsoft Entra External ID product receives a final disposition.
