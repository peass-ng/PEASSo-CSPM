# Azure Virtual Machine Scale Sets public exposure source proof

The [VMSS network guide](https://learn.microsoft.com/en-us/azure/virtual-machine-scale-sets/virtual-machine-scale-sets-networking) documents per-instance public IPs and load balancer frontends. The read-only [instance NIC LIST](https://learn.microsoft.com/en-us/rest/api/virtualnetwork/network-interfaces/list-virtual-machine-scale-set-network-interfaces?view=rest-virtualnetwork-2018-10-01) and [scale-set public IP LIST](https://learn.microsoft.com/en-us/rest/api/virtualnetwork/public-ip-addresses/list-virtual-machine-scale-set-public-ip-addresses?view=rest-virtualnetwork-2018-10-01) expose the actual IP configuration binding, assigned address, and NIC security-group references. The collector makes one cached, paginated request for each list per scale set and validates child paths before projection.

`internet_exposure._azure_vm_scale_set` joins assigned instance addresses to NIC and subnet NSGs. VMSS NICs also feed load balancer and application gateway backend joins. The load balancer assessment recognizes [legacy inbound NAT pools and current V2 NAT rules](https://learn.microsoft.com/en-us/azure/load-balancer/inbound-nat-rules) with frontend port ranges. Incomplete lists or broken joins remain UNKNOWN.
