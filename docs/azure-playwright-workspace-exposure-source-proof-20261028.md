# Playwright Workspaces exposure source proof

The [subscription LIST API](https://learn.microsoft.com/en-us/rest/api/playwright/resourcemanager/playwright-workspaces/list-by-subscription?view=rest-playwright-resourcemanager-2025-09-01) for `Microsoft.LoadTestService/playwrightWorkspaces` returns `dataplaneUri`, `localAuth`, and `provisioningState` in the resource properties. It is read-only, paged, and uses API version `2025-09-01`. The [workspace access guide](https://learn.microsoft.com/en-us/azure/app-testing/playwright-workspaces/how-to-manage-workspace-access) assigns access with Azure RBAC. [Access-token guidance](https://learn.microsoft.com/en-us/azure/app-testing/playwright-workspaces/how-to-manage-access-tokens) says token authentication is disabled by default, can be enabled, and tokens are tied to a user and checked against current RBAC. Token values cannot be retrieved after creation.

The collector uses its existing cached ARM subscription LIST path and retains only identity, location, data-plane URI, local-auth mode and provisioning state. It excludes all unknown properties and token material. Native analysis reports the returned HTTPS host as an authenticated public TCP/443 endpoint for a succeeded workspace and records whether service tokens are enabled. A missing or malformed endpoint or unready state remains UNKNOWN. Generic Azure role-assignment analysis handles observed third-party RBAC grants. A token's actual holder or downstream sharing cannot be determined from the management LIST response or recovered token values.

[Microsoft Playwright Testing (Classic) retired on March 8, 2026](https://learn.microsoft.com/en-us/rest/api/playwright/includes/retirement-banner). Microsoft directs users to create a new Playwright Workspace under Azure App Testing. The former `Microsoft.AzurePlaywrightService/accounts` resource is distinct from the current `Microsoft.LoadTestService/playwrightWorkspaces` resource; this implementation addresses the current service.
