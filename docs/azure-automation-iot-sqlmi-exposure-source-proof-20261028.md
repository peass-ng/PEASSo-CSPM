# Automation, IoT Hub, and SQL Managed Instance exposure source proof

The [Azure Automation webhook guide](https://learn.microsoft.com/en-us/azure/automation/automation-webhooks) says an enabled, unexpired webhook exposes a public HTTP URL whose bearer token permits runbook invocation without further authentication; the URL is retrievable only at creation. The existing collector lists webhooks once per account and stores only enabled and expiry metadata, never the token-bearing URI. The native assessment detects active webhook invokability and leaves denied or malformed inventory UNKNOWN. It does not claim to know who received the URL.

The [IoT Hub networking guide](https://learn.microsoft.com/en-us/azure/iot-hub/iot-hub-ip-filtering) documents `networkRuleSets.defaultAction` and allowed IP ranges; [public network access](https://learn.microsoft.com/en-us/azure/iot-hub/iot-hub-public-network-access) blocks the public path when Disabled. The [ARM schema](https://learn.microsoft.com/en-us/azure/templates/microsoft.devices/2023-06-30/iothubs) supplies those fields. Existing subscription LIST inventory feeds a native assessment of the public HTTPS, AMQP, and MQTT listeners and their IP gate. Missing controls remain UNKNOWN. Built-in Event Hubs endpoint exceptions remain a residual UNKNOWN.

The [SQL Managed Instance public endpoint guide](https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/public-endpoint-configure?view=azuresql) documents the two-step exposure path: `publicDataEndpointEnabled` plus an NSG rule admitting TCP/3342 on the instance subnet. The [ARM resource schema](https://learn.microsoft.com/en-us/azure/templates/microsoft.sql/managedinstances) exposes the endpoint flag. Existing cached instance, subnet, and NSG inventory feeds the native assessment. It blocks disabled endpoints, reports a public listener only when the NSG allows it, and leaves missing subnet or NSG evidence UNKNOWN. Route overrides remain a residual UNKNOWN.
