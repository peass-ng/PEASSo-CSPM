# MySQL Flexible Server exposure source proof

The existing per-subscription server LIST now uses the read-only `2024-12-30` ARM API, whose [server LIST schema](https://learn.microsoft.com/en-us/rest/api/mysql/servers/list-by-resource-group?view=rest-mysql-2024-12-30) includes `databasePort`, `network.publicNetworkAccess`, and optionally `privateEndpointConnections`. The detector uses the reported port, with 3306 only when `databasePort` is absent. An invalid reported port is unresolved.

When the server response embeds private endpoint connections, the collector validates and projects those rows without another call. Otherwise it uses the read-only, paged [private endpoint connection LIST](https://learn.microsoft.com/en-us/rest/api/mysql/private-endpoint-connections/list-by-server?view=rest-mysql-2024-12-30). A missing, malformed, or denied child inventory remains unknown. Only connection identity, approval, provisioning state, and the remote private endpoint ID enter the snapshot. The [MySQL networking guide](https://learn.microsoft.com/en-us/azure/mysql/flexible-server/concepts-networking-private-link) says Private Link can be connected across subscriptions and remains a path when public access is disabled. An approved, provisioned foreign endpoint is reported as a third-party route, subject to database authentication.

The [ARM resource schema](https://learn.microsoft.com/en-us/azure/templates/microsoft.dbformysql/2024-12-30/flexibleservers) documents the configurable database port. The read-only firewall-rule LIST already collected by the Azure collector continues to determine the public route.
