# Management-group RBAC exposure source proof

- [Azure role assignments](https://learn.microsoft.com/en-us/azure/role-based-access-control/role-assignments) can be scoped to a management group; the scope is the set of resources a principal can access, and its role definition specifies permissions. The [management-group GET API](https://learn.microsoft.com/en-us/rest/api/managementgroups/management-groups/get) returns the hierarchy and tenant ID.
- The existing Azure collector lists management groups and their details, then reads role assignments and role definitions at each group and the tenant root through cached, read-only authorization LISTs. A selected `management_group` inventory now requests directory principals and memberships as dependencies so external principal classification has evidence.
- `peaso.analysis.internet_exposure._azure_management_group` joins direct group-scope and tenant-root assignments to role definitions, Graph principal ownership, and guest members of assigned groups. It flags unconditional declared external grants, preserves UNKNOWN for incomplete assignment, role, identity, group-membership, exclusion, or condition evidence, and never claims effective use of the grant.
