# Defender EASM endpoint and data export source proof

Microsoft's [EASM REST overview](https://learn.microsoft.com/en-us/rest/api/defenderforeasm/) distinguishes control-plane workspaces from data-plane data connections. The [data-connection LIST API](https://learn.microsoft.com/en-us/rest/api/defenderforeasm/dataplanepreview/data-connections/list-data-connection?view=rest-defenderforeasm-dataplanepreview-2024-10-01-preview) uses a regional HTTPS endpoint and `https://easm.defender.microsoft.com/.default` scope. [Authentication guidance](https://learn.microsoft.com/en-us/rest/api/defenderforeasm/authentication) requires a Microsoft Entra bearer token. A provisioned workspace therefore has an authenticated public regional HTTPS endpoint; this is an inference from the documented data-plane URL and the [workspace ARM schema](https://learn.microsoft.com/en-us/azure/templates/microsoft.easm/workspaces), which contains no private-network setting.

The LIST sample includes a Log Analytics `apiKey`, and the [connection schema](https://learn.microsoft.com/en-us/rest/api/defenderforeasm/dataplanepreview/data-connections/get-data-connection?view=rest-defenderforeasm-dataplanepreview-2024-10-01-preview) includes the key alongside the workspace ID. The collector makes one cached, paginated read per observed workspace and constructs an allowlisted record containing only active state, export content/frequency and Log Analytics workspace ID or Data Explorer cluster/database/region. It never places `apiKey`, arbitrary properties or raw URLs in the snapshot. Unknown or denied reads stay incomplete.

The [product guide](https://learn.microsoft.com/en-us/azure/external-attack-surface-management/data-connections) says these connections send EASM asset/insight data to Log Analytics or Azure Data Explorer. Neither returned connection type identifies the destination tenant or downstream readers. Native analysis reports active configured exports as `UNKNOWN` and inactive connections as blocked. Complete third-party receipt cannot be decided from the EASM read API alone.
