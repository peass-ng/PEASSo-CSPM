# Azure Analysis Services exposure source proof

- [Analysis Services server GET](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers/get-details?view=rest-analysisservices-2017-08-01) documents the read-only resource detail operation, `serverFullName`, `state`, server administrators, IPv4 firewall ranges, the Power BI service exception, and `backupBlobContainerUri`. The latter is a SAS container URI and is discarded before snapshot storage.
- [Connection guide](https://learn.microsoft.com/en-us/analysis-services/azure-analysis-services/analysis-services-connect?view=sql-analysis-services-2025) documents the `asazure://` server name and HTTPS connections. [Service overview](https://learn.microsoft.com/en-us/analysis-services/azure-analysis-services/analysis-services-overview?view=sql-analysis-services-2025) says firewall protection is disabled by default on new servers and, when enabled, admits only configured source ranges.
- [Firewall setup](https://learn.microsoft.com/en-us/analysis-services/azure-analysis-services/analysis-services-qs-firewall?view=sql-analysis-services-2025) describes the Power BI service exception and IP ranges. The native rule infers that a complete server GET with no `ipV4FirewallSettings` has the documented default of no firewall protection; configured public source ranges or the Power BI exception are also exposed. Complete private-only ranges with the Power BI exception disabled block client ingress. Malformed or incomplete firewall metadata stays `UNKNOWN`.
- [User permissions](https://learn.microsoft.com/en-us/analysis-services/azure-analysis-services/analysis-services-manage-users?view=sql-analysis-services-2025) documents B2B guest administrators and database-role users. [Analysis Services DMVs](https://learn.microsoft.com/en-us/analysis-services/instances/use-dynamic-management-views-dmvs-to-monitor-analysis-services?view=sql-analysis-services-2025) expose model role memberships through the data plane and require server administrator permission. The ARM server read does not prove model-role membership or external identity ownership; those remain a separate coverage gap.

`peaso/collectors/azure.py` performs one cached GET per listed server and retains only listener, firewall, and administrator metadata. `peaso/analysis/internet_exposure.py:_azure_analysis_server` gives a deterministic public listener verdict. Focused fake-transport tests are in `tests/test_peaso_azure_analysis_services_exposure.py`; no Azure write operation is used.
