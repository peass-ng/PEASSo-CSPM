# Azure Cost Management export exposure source proof

The [2025-03-01 Exports List API](https://learn.microsoft.com/en-us/rest/api/cost-management/exports/list?view=rest-cost-management-2025-03-01) returns configured exports for subscription, resource group, management group, billing account, department, enrollment account, billing profile, invoice section, and partner customer scopes. Its `deliveryInfo.destination.resourceId` identifies an Azure Storage account. A second destination form uses `storageAccount` and a `sasToken`; Microsoft says that partner form can target a storage account in any tenant, and the returned token is obfuscated.

The collector enumerates those scopes with the read-only [billing account](https://learn.microsoft.com/en-us/rest/api/billing/billing-accounts/list?view=rest-billing-2024-04-01), [billing profile](https://learn.microsoft.com/en-us/rest/api/billing/billing-profiles/list-by-billing-account?view=rest-billing-2024-04-01), [invoice section](https://learn.microsoft.com/en-us/rest/api/billing/invoice-sections/list-by-billing-profile?view=rest-billing-2024-04-01), [department](https://learn.microsoft.com/en-us/rest/api/billing/departments/list-by-billing-account?view=rest-billing-2024-04-01), [enrollment account](https://learn.microsoft.com/en-us/rest/api/billing/enrollment-accounts/list-by-billing-account?view=rest-billing-2024-04-01), and [partner customer](https://learn.microsoft.com/en-us/rest/api/billing/customers?view=rest-billing-2024-04-01) LIST APIs, reusing existing resource group and management group inventories. It retains only the export identity, source scope, destination storage resource ID, and a boolean for the partner destination form. It does not retain the SAS token or other billing fields. All reads use the scan's existing request cache.

The native evaluator reports a configured cross-subscription destination when an export under a subscription or resource group points to a storage account in another subscription. A same-subscription storage destination passes this specific external-delivery check. Billing-scope destinations and partner SAS destinations remain `UNKNOWN`: the API does not establish that the storage account belongs to the billing account's tenant or identify the partner destination's tenant. A configured destination is evidence of delivery capability, not proof that a scheduled or on-demand export has run.

Focused verification: `tests/test_peaso_azure_cost_export_exposure.py` checks destination decisions, scope enumeration, one export LIST per scope, and removal of SAS and billing display-name material. The normal source-validated Azure exposure suite passed 79 tests on this branch.
